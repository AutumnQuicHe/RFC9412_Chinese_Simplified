ORIGIN帧的布局与HTTP/2中使用的布局几乎相同；为清晰起见，此处重新陈述相关信息。ORIGIN帧类型为`0x0c`（十进制12），与HTTP/2中一致。负载包含零个或多个Origin-Entry字段的实例。

```
HTTP/3 Origin-Entry {
  Origin-Len (16),
  ASCII-Origin (..),
}

HTTP/3 ORIGIN Frame {
  Type (i) = 0x0c,
  Length (i),
  Origin-Entry (..) ...,
}
```
**图1：ORIGIN帧布局**

一个Origin-Entry是一个以长度分隔的字符串。具体而言，它包含两个字段：

Origin-Len：
: 一个无符号的16位整数，指示ASCII-Origin字段的长度，以八位字节为单位。

ASCII-Origin：
: 一个**可选**的字符序列，包含发送方声称此连接对其具有或可能具有权威性的源站的ASCII序列化形式（[RFC6454]的[第6.2章](https://www.rfc-editor.org/info/rfc6454/#section-6.2)）。
